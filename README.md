# CloudBioIntegrator

CloudBioIntegrator is a containerized framework for standardized analysis of single-cell
RNA-seq (scRNA-seq) and 10x Visium spatial transcriptomics data. It couples a unified
preprocessing regime and fixed intermediate tables with a curated method library (Scanpy,
Seurat v5, Harmony, scVI, RCTD, Tangram, and optional cell2location), and reports
cross-method concordance, perturbation sensitivity, and operational feasibility as
first-class evidence.

## Repository contents

- `scripts/` — pipeline orchestration, method runners (Python/R), figure generation, and
  analysis/benchmark scripts. Every figure (F1-F6) and every results table is produced by
  these scripts from public inputs.
- `results/` — generated evidence tables (`benchmarks/`, `figures/`, `effect_sizes/`,
  `audit/`) and cross-environment run manifests (`runs/`).
- `plots/publication/` — the main figures generated by `scripts/figures/`.
- `docs/` — method libraries, data/compute plans, runbooks, evaluation matrix, claim
  register, and the cross-environment verification record.
- `data/manifest.tsv` — authoritative dataset sources and integrity metadata.
- `schemas/` — action contract schema used by the pipeline.

## Reproduce from scratch

1. Build the pinned container:

   ```bash
   docker build -t cloudbiointegrator:local .
   ```

2. Run the contract check and an end-to-end smoke test:

   ```bash
   make skeleton
   make smoke
   ```

3. Fetch datasets and run analyses, or regenerate figures directly:

   ```bash
   python3 scripts/data/fetch_dataset.py --help
   make figures
   ```

4. Record and compare run manifests for cross-environment checks:

   ```bash
   python3 scripts/audit/record_run_manifest.py --help
   python3 scripts/audit/compare_run_manifests.py --help
   ```

Detailed dataset acquisition, compute planning, and reproduction checklists are provided in
`docs/DATA_PLAN.md`, `docs/COMPUTE_PLAN.md`, and `docs/FINAL_CLOUD_REPRO_CHECKLIST.md`.

## Cross-environment verification

Run-scoped output artifacts for the declared minimal pipeline were verified byte-identical
(SHA-256) across three independent environments: the local containerized runtime, a second
container stack (python:3.12-slim), and a public cloud Linux container (ModelScope). The
manifests are archived under `results/runs/` and summarized in `docs/CROSS_ENV_RESULT.md`;
the CI workflow in `.github/workflows/repro-check.yml` automates the same comparison.

## Datasets

All inputs are public: 10x Genomics PBMC and Visium benchmark datasets, and the Allen cortex
scRNA reference. Sources and integrity metadata are recorded in `data/manifest.tsv`; the
dataset landscape and acquisition steps are documented in `docs/DATASET_LANDSCAPE.tsv` and
`docs/DATA_PLAN.md`.

## Method library and evaluation

The supported method layers and their parameterization are documented in
`docs/METHOD_LIBRARY_SCRNA.md` and `docs/METHOD_LIBRARY_VISIUM.md`. The evaluation matrix,
predeclared metrics, and claim-to-evidence mapping are recorded in `docs/EVALUATION_MATRIX.tsv`
and `docs/CLAIMS.tsv`.
